# Metronome

面向音乐练习的 Rust TUI 节拍器。Ratatui + Crossterm 提供终端交互，Rodio 合成声音，不需要外部音频素材。

## 运行

```sh
cargo run --release
```

请使用交互式终端，Windows 推荐 Windows Terminal。建议窗口至少 60×24；小窗口显示精简视图。

### 安装为命令行应用

在项目目录执行：

```sh
cargo install --path . --locked
```

确保 Cargo 可执行目录在 `PATH` 中（Windows 通常为 `%USERPROFILE%\.cargo\bin`），之后可以在任意目录运行 `metronome`。更新已安装版本使用 `cargo install --path . --locked --force`；更新不会清除用户配置。

当前版本为 `0.1.0`，对应 Git tag `v0.1.0`。版本记录见 [CHANGELOG.md](CHANGELOG.md)。

实验性的 ASIO 多客户端探测工具独立于普通节拍器，使用可选 feature 构建，说明见 [ASIO_PROBE.md](docs/ASIO_PROBE.md)。

新增实验性的 **CLAP 干声桥接插件 + TUI 输入监视页**，按 `I` 查看电平和波形；构建、安装及 REAPER Monitoring FX 用法见 [AUDIO_BRIDGE.md](docs/AUDIO_BRIDGE.md)。这不是起音评分工具，尚未完成延迟校准。

首次运行默认 120 BPM、每小节 4 拍；以后自动恢复上次设置，始终暂停，按空格开始。BPM 始终以四分音符为基准：120 BPM 的八分音符细分每秒响 4 次，三连音每秒响 6 次。

## 功能

- 每小节 1–12 拍，速度 30–300 BPM。
- 四分音符、八分音符、三连音、十六分音符细分。
- 首拍 / 普通正拍 / 细分拍三层相对音量，分别乘以主音量。细分音量设为 0 时，视觉细分仍继续。
- 清脆（Crisp）、柔和（Soft）、木块风格（Wood）三种合成声音预设。
- 首拍声音略有区别，音量层级可自由调整。
- 点击测速：取最近最多 6 次点击的平均速度，间隔超过 2 秒重新计数。
- 音频初始化失败时自动保留视觉节拍。
- 自动保存练习设置，方便继续上次训练。
- 静默小节训练：循环播放 N 小节、静默 M 小节，静默期间视觉节拍继续。
- 可编程节奏网格：1–4 小节循环，每点可以不响、普通音或重音，支持复制小节与撤销。

这里的「每小节拍数」不等同于完整的音乐拍号；三连音细分也不等同于 6/8 拍。暂不提供复合拍分组、摇摆节奏或参考音。

## 键盘操作

| 按键 | 功能 |
| --- | --- |
| Space | 开始 / 暂停，重新开始时从小节首拍播放 |
| ↑ / ↓ 或 + / - | BPM ±1 |
| PageUp / PageDown | BPM ±10 |
| ← / → 或 Tab | 选择速度、每小节拍数、细分、声音预设 |
| Enter | 编辑所选参数 |
| S | 细分选择弹窗 |
| V | 音量面板：↑↓ 选择，←→ 调整 5%，即时生效 |
| G | 静默训练面板：↑↓ 选择，←→ 调整小节数 |
| E | 打开节奏编辑页并启用自定义节奏 |
| I | 打开干声音频监视页，N 选择实例、C 选择通道、R 重新连接 |
| P | 在普通节拍器 / 自定义节奏模式间切换，保留两套节奏设置 |
| T | 点击测速 |
| M | 整体静音 / 恢复 |
| R | 重置默认设置并暂停 |
| : | 搜索命令，Tab 补全，Enter 执行 |
| ? | 帮助 |
| Q / Esc | 在主界面退出 |
| Ctrl+C | 随时退出 |

弹窗里 Esc 只关闭弹窗，不退出应用。数字编辑与节奏选择使用 Enter 确认、Esc 取消；混音及训练面板关闭时保留调整。弹窗不会停止节拍，文字输入不会触发主界面快捷键。

播放中速度与音量即时更新；每小节拍数、细分和训练设置在下一小节生效，主界面会显示排队提示。

## 配置持久化

设置变化停止 500 毫秒后自动保存，退出时再保存尚未写入的设置。保存 BPM、每小节拍数、细分、声音预设、四层音量、静默训练参数及完整的自定义节奏；不保存播放状态、临时静音状态、当前拍、编辑光标、撤销历史和点击测速记录。旧版配置未包含节奏网格时，会使用默认网格。

配置保存在系统用户配置目录的 `config.toml` 中，具体路径显示在界面 `Config` 状态行。文件采用 TOML 格式，可退出应用后手动编辑。通过同目录临时文件替换原文件，避免直接写入损坏旧配置。

文件缺失时使用默认值并自动创建。内容错误、参数越界或版本不支持时使用默认值，并**禁用本次会话的保存以保护原文件**；修正文件后重启即可。保存失败不会中断节拍，会在界面及退出时提示。`R` 重置也会自动保存默认设置（静默训练关闭）。

## 静默小节训练

按 `G` 设置响声小节数（1–32）与静默小节数（0–32），或使用 `:training 4 2`：响 4 小节、静默 2 小节，持续循环。将静默小节设为 0，或执行 `:training off`，即可关闭训练。

主界面显示 `SOUND 1/4` 或 `SILENT 1/2` 等阶段与进度。静默小节不播放首拍、正拍或细分声音，但保持同样速度与视觉提示。与 `M` 整体静音独立；取消整体静音不会取消静默训练。

开始播放时从响声阶段的第一小节开始。播放中修改训练设置在下一小节生效，并从新的响声阶段重新计数。调速、调音量或切换细分不会重置训练循环。

## 可编程节奏网格

按 `E` 打开编辑页并启用网格模式，按 `B` 设置 1–4 小节、每小节 1–12 个四分音符拍、每拍 1/2/3/4/6/12 个点。全段使用统一的拍数与网格密度，BPM 始终以四分音符为基准。

默认网格是一小节、四拍、每拍四点，只在正拍发声：

```text
         1     2     3     4
Bar 1    X...  x...  x...  x...
```

`.` 不响、`x` 普通音、`X` 重音。普通音在正拍使用正拍音量，在细分位置使用细分音量；重音无论在哪里都使用重音音量与声音。空点仍占据完整时间，不会压缩节奏。

| 编辑页按键 | 功能 |
| --- | --- |
| ← / → | 移动到相邻点，跨正拍，当前小节内循环 |
| ↑ / ↓ | 切换小节 |
| Home / End | 当前小节第一个 / 最后一个点 |
| Space | 当前点普通音 / 不响（已是重音时也可关闭） |
| A | 当前点切换重音；空点直接设为重音 |
| Enter | 开始 / 暂停试听，从第一小节重新开始 |
| B | 修改小节数、拍数、每拍点数 |
| C | 清空当前小节 |
| F | 填满当前小节，第一点重音，其余普通音 |
| Y | 复制当前小节到下一小节，最后一小节复制到第一小节 |
| U | 撤销最近最多 64 次编辑，包括尺寸调整 |
| P | 自定义节奏 / 普通模式切换 |
| + / -、PageUp / PageDown | 调整 BPM；方向键在编辑页只移动光标 |
| V / G / M / T / : | 音量、训练、静音、点击测速、命令面板 |
| Esc / E | 返回主界面，不停止播放、不禁用自定义节奏 |
| Q / Ctrl+C | 退出应用 |

编辑光标与播放位置分别用高亮、绿色下划线表示；密集网格随光标按整拍滚动。编辑通过上述自动保存机制持久化，播放中的点位修改和模式切换在下一小节生效。单点编辑不重置多小节循环；修改网格尺寸或模式会在生效时从节奏第一小节开始。

调整密度时只保留仍落在相同时间位置的点。例如每拍 4 点变为 6 点，原本的半拍点会从第 3 点移动到第 4 点；四分之一拍位置无法准确表示时会丢弃。新增小节和新增点默认不响；缩小尺寸会丢弃被移除的内容。在编辑页可按 `U` 撤销。

自定义节奏与静默训练分别循环：例如三小节节奏与「响一小节 / 静默一小节」训练同时运行，静默不会暂停或重置节奏位置。高密度时自动缩短点击声以避免声音长度超过点间隔；终端可能无法显示每一个高速点，但不会据此删减音频节拍。

当前自动保存一套网格，不提供命名节奏库或多轨编辑。普通模式原本的拍数和细分保持独立；网格模式中主界面的 Enter 编辑有效网格拍数，`S` 打开网格密度设置。

## 命令

按 `:` 后输入（不用再次输入冒号）：

```text
bpm 132
beats 3
subdivision quarter
subdivision eighth
subdivision triplet
subdivision sixteenth
volume master 80
volume accent 100
volume beat 75
volume subdivision 35
voice crisp
voice soft
voice wood
training 4 2
training off
pattern edit
pattern on
pattern off
pattern bars 2
pattern beats 4
pattern density 12
play
pause
mute
reset
quit
```

音量范围为 0–100。可输入 `trip` 搜索三连音命令，再按 Tab 补全；数值命令补全后需要输入参数。

### 代码结构

- `src/main.rs`：应用入口和终端事件循环。
- `src/app.rs`：应用状态、速度、音量和训练参数。
- `src/audio.rs`：节拍调度、合成声音和音频播放。
- `src/input.rs`：快捷键、弹窗输入和命令解析。
- `src/ui.rs` / `src/grid.rs`：主界面、弹窗和节奏编辑页。
- `src/pattern.rs`：节奏网格、尺寸转换和编辑历史。
- `src/config.rs`：配置验证、恢复与自动保存。
- `src/monitor.rs` / `src/input_view.rs`：后台音频接收分析及输入监视页。
- `crates/audio-bridge`：跨进程有界音频队列与接收 API。
- `crates/bridge-plugin`：CLAP 原样透传插件。

`Cargo.lock` 随应用代码提交，`target/` 与 `dist/` 构建产物不纳入版本控制。新增宿主音频接收，但当前不包含吉他起音检测或节奏偏差评分；这些功能将作为后续迭代开发。

节拍调度在独立线程中使用绝对截止时间，避免累计睡眠漂移；系统停顿后不追赶播放积压节拍。系统调度、音频缓冲与终端刷新仍会造成延迟，声音和画面不能保证采样级同步，这不是硬实时音频工具。

Linux 构建需要 ALSA 开发库，例如 Debian/Ubuntu 的 `libasound2-dev`。默认使用系统默认音频输出设备，第一版不支持运行中切换或重新连接音频设备。
